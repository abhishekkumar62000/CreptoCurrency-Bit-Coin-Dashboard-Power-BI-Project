# 🚀 Cryptocurrency Bit Coin Dashboard Power BI Project 💰📊

Welcome to my **Cryptocurrency Bit Coin Dashboard Project**! In this project, I used a messy raw dataset and transformed it into insightful and visually compelling reports using **Excel**, **Python**, **SQL**, and **Power BI**. Here's how I made it happen:

## 🌟 Project Overview:
- **Goal:** Transform raw cryptocurrency data into a powerful, insightful, and interactive Bitcoin dashboard.
- **Tools Used:**  
  - Excel 📈  
  - Python 🐍  
  - SQL 💾  
  - Power BI 🔥

---

## 🔧 Key Steps in Building the Project:

### 1. **Data Collection 📥**
- Collected raw cryptocurrency dataset containing Bitcoin prices, market data, trading volumes, and timestamps.

### 2. **Data Cleaning & Preprocessing 🧹**
- Cleaned the data using **Excel** to remove missing values and ensure consistency in formatting. ✨  
- Performed data wrangling with **Python** (Pandas, NumPy) to transform the data into a usable format for analysis.

### 3. **Data Analysis with Python 🧠**
- Used **Python** for detailed exploratory data analysis (EDA) to uncover trends, anomalies, and correlations. 📊  
- Visualized patterns in Bitcoin’s market behavior, such as price fluctuations over time.

### 4. **SQL for Data Manipulation 💾**
- Applied **SQL** queries to extract, aggregate, and filter data from the raw dataset efficiently. 🖥️  
- Cleaned and joined different data sources for more comprehensive analysis.

### 5. **Power BI Dashboard Creation 📊**
- Built an interactive **Power BI dashboard** to visualize Bitcoin trends in price, market cap, trading volumes, and more. 🔥  
- Created dynamic visualizations that allow users to explore data on various time scales, from daily to yearly.
